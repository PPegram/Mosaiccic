Website information

Accessibility.

We want people to be able to read this website and use its links with a keyboard, a screen reader or a touch device. This page describes the features included and how to report a problem.

Features included

  • A skip link to get past the navigation.
  • Semantic headings and labelled navigation.
  • Text alternatives for informative images.
  • Visible keyboard focus and a mobile menu that closes with Escape.
  • Light and dark colours, using your system preference by default.
  • Layouts that adapt to smaller screens and reduced-motion preferences.

Known limitations

Contact currently depends on LinkedIn, which may require an account. That creates an access barrier for visitors who do not use the service. The website has not had an independent accessibility audit, so these features should not be read as a certification of WCAG compliance.

Report a problem

If you can access LinkedIn, contact Phil Pegram with the page address, the task you were trying to complete and any assistive technology or browser involved. Please say what format or change would help.
