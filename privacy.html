Website information / 4 October 2026

Website privacy.

This page describes this website’s current technical setup. Any future research study will need separate participant information and a study-specific privacy notice.

Browsing this site

The website does not contain analytics scripts, advertising trackers, embedded social feeds or a contact form. Images and fonts are hosted with the site, and the colour preference lasts for the current page visit without being saved to browser storage.

Hosting

The hosting provider may process connection information such as IP addresses and technical request logs when serving a page. Once hosted on GitHub Pages, GitHub’s handling of that information is described in the GitHub General Privacy Statement. A preview hosted elsewhere is subject to that provider’s practices.

Contact through LinkedIn

Contact links open LinkedIn, which processes information under its own privacy policy. Please send only the information needed to explain your enquiry, and avoid sensitive personal details in an initial message.

Questions about information you have shared

Contact Phil Pegram on LinkedIn to ask about information you have shared with MOSAIC, or to raise a privacy concern. We’ll need to understand the request and confirm any necessary details before responding.

Changes to the site

If forms, analytics, newsletter subscriptions or other data-processing features are added, this page will need updating before those features are enabled.
